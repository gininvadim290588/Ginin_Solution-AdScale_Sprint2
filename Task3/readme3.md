##### Цель
Спроектировать стратегию хранения данных, масштабирования и отказоустойчивости для целевой архитектуры AdScale.

Основные решения:
* Database per Service;
* CQRS для аналитики;
* Redis как слой горячих данных;
* Kafka как центральная шина событий;
* PostgreSQL для транзакционных сервисов;
* ClickHouse для аналитики;
* репликация и шардирование для масштабирования;
* cрезервное копирование и Disaster Recovery.
