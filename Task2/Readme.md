## Проектирование RTB-сервиса и интеграции с DSP

Цель проекта — обеспечить интеграцию AdScale с новой DSP-площадкой без деградации SLA и создать основу для масштабирования платформы до 50 000 RPS.

Основные архитектурные решения:
* Выделение Bidding Service из монолита как первого микросервиса.
* Использование gRPC для внутренних синхронных вызовов критического пути.
* Использование Kafka для асинхронной обработки событий показов и кликов.
* Использование API Gateway для внешних DSP-интеграций.
* Использование Redis для хранения горячих данных кампаний и ставок.
* Применение паттернов Circuit Breaker, Retry, Timeout и Fallback.
* Идемпотентность финансовых операций.
* Горизонтальное масштабирование всех критичных компонентов.
